Presence Studio 1.1.0 — Discord Rich Presence Manager для Windows 10/11 x64.

- Новый тёмный дизайн: вкладки, округлые карточки, акцентные кнопки и предпросмотр.
- Чёткая типографика DirectWrite, векторная отрисовка Direct2D, поддержка DPI каждого монитора.
- Работа в фоне: крестик и сворачивание прячут окно в трей, не прерывая статус, таймер и автосмену.
- Меню трея: открыть, скрыть активность, полностью выйти. Повторный запуск возвращает существующее окно.
- Значок приложения в нескольких разрешениях, восстановление значка после перезапуска Проводника.

- Нативное приложение на C++17 с русским интерфейсом.
- Название, две строки текста, автосмена вариантов, большая и малая картинки с подписями.
- Прошедшее время, смещение старта и обратный отсчёт.
- JSON-профили, автосохранение применённых настроек, текстовый предпросмотр.
- Локальный Discord RPC без пользовательского токена, переподключение и сообщения об ошибках.

Распакуйте `DiscordPresenceManager-Windows-x64.zip` и запустите EXE. Нужны настольный Discord и Application ID из Discord Developer Portal. Подробная инструкция — в README внутри архива.

Проверки: тесты модели, интеграционный тест RPC с отдельным mock-сервером и тест жизненного цикла окна (закрытие в трей, автосмена в фоне, DPI и полный выход). Отображение на реальном аккаунте требует вашего Application ID и запущенного Discord. Изображения смотрите в профиле Discord; менеджер показывает предпросмотр текста и таймера.
