Presence Studio 1.2.0 — циклическая автосмена полных статусов.

- Новая вкладка **04 Автосмена**: до 100 статусов, каждый со своей длительностью от 15 секунд до 24 часов.
- Запись хранит весь набор: Application ID, название, две строки текста, большую и малую картинки, подписи и таймер.
- Добавление из формы, редактирование, замена, удаление и изменение порядка.
- Запуск с первого статуса, переход по списку и автоматический повтор по кругу. Справа — текущая запись и обратный отсчёт до следующей.
- Работа в фоне и трее; корректное продолжение после сна компьютера.
- «Остановить цикл» оставляет текущий статус, «Скрыть статус» прекращает автосмену и удаляет активность.
- Сохранение списка между запусками, импорт и экспорт JSON. Совместимость с профилями 1.1.

Как пользоваться: настройте статус в первых трёх вкладках → откройте «Автосмена» → задайте время в секундах → «+ Добавить». Повторите для остальных и нажмите «Запустить цикл».

Распакуйте `DiscordPresenceManager-Windows-x64.zip` и запустите EXE. Дополнительные пакеты, Visual C++ Redistributable и Python не нужны. Требуются Windows 10/11 x64, настольный Discord и Application ID из Discord Developer Portal.

Проверки: модель присутствия, границы длительностей, повтор списка, восстановление после задержек, JSON и старые профили, локальный RPC, автосмена полных статусов скрытого окна, DPI и трей. GitHub Actions дополнительно запускает готовый EXE на windows-2022 и windows-2025 с системным PATH и проверяет DLL-зависимости.
